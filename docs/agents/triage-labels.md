# Triage Labels

工程技能使用五個標準分流角色。
下表定義各角色在本儲存庫議題追蹤系統中對應的實際標籤。

| 標準角色 | 實際標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由無人值守的代理執行 |
| `ready-for-human` | `ready-for-human` | 需要由人員實作 |
| `wontfix` | `wontfix` | 不予處理 |

當技能要求套用某個分流角色時，使用「實際標籤」欄位中的字串。

若日後更換標籤名稱，修改「實際標籤」欄位，保留標準角色不變。
